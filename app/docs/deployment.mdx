## Setup Instructions

### Prerequisites

```bash
# Clone smart contract repository
git clone https://github.com/shriyashsoni/yelid-mind-smart-contract.git
cd yelid-mind-smart-contract

# Install dependencies
npm install

# Copy environment configuration
cp .env.example .env
```

### Environment Variables

Create `.env` file with:

```env
PRIVATE_KEY=your_private_key_here
RPC_URL=https://rpc-amoy.polygon.technology/
ETHERSCAN_API_KEY=your_etherscan_key
DEPLOYER_ADDRESS=your_wallet_address
```

### Compilation

```bash
npm run build
# or
npm run compile
```

### Deployment

```bash
# Deploy all contracts to Amoy testnet
npm run deploy:amoy

# Deploy specific contract
npm run deploy:amoy -- --contract YieldVaultV4
```

## Integration with Frontend

### 1. Update Contract Addresses

File: `lib/contract-abis.ts`

```typescript
export const CONTRACT_ADDRESSES = {
  AMOY: {
    YLDToken: '0x030e4Dfc7D89e6251Ef06ADbC536A85357BCb28c',
    YieldVaultV4: '0x5A5Fc9066AbeC751577bA3BD330555E54e3aA8e3',
    RiskGuard: '0x3CAb3d9b205DBc5dB656c16743fc88C301d0ad6A',
    // Add newly deployed contracts here
  },
};
```

### 2. Update Configuration

File: `lib/deployment-config.ts`

```typescript
export const DEPLOYMENT_CONFIG = {
  network: {
    name: 'Polygon Amoy',
    chainId: 80002,
    rpcUrl: 'https://rpc-amoy.polygon.technology/',
    explorerUrl: 'https://amoy.polygonscan.com',
  },
  // ... rest of config
};
```

### 3. Contract Interaction

Use the provided hooks:

```typescript
import { useContractRead, useContractWrite } from '@/hooks/use-contract-interaction';

// Reading contract data
const { data, isLoading } = useContractRead({
  address: CONTRACT_ADDRESSES.AMOY.YieldVaultV4,
  abi: YIELD_VAULT_V4_ABI,
  functionName: 'getTotalAssets',
});

// Writing to contract
const { write, isLoading } = useContractWrite({
  address: CONTRACT_ADDRESSES.AMOY.YieldVaultV4,
  abi: YIELD_VAULT_V4_ABI,
  functionName: 'deposit',
});
```

## Troubleshooting

### Contract Not Deploying

1. Check private key in `.env`
2. Verify wallet has MATIC tokens for gas fees
3. Check RPC endpoint availability
4. Review deployment logs for specific errors

### Interaction Errors

1. Ensure network is set to Polygon Amoy (80002)
2. Verify contract addresses are correct
3. Check wallet balance for gas fees
4. Review contract state requirements

### PolygonScan Verification Issues

1. Ensure source code is public on GitHub
2. Use correct constructor arguments
3. Match compiler version
4. Enable contract optimization settings
